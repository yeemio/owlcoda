安装

在 macOS / Linux / Windows 上 5 分钟内安装 OwlCoda npm 包。

OwlCoda 可以通过 npm 公开安装。从 v0.15.0 源码发布开始，公仓也承载 OwlCoda 的 GPL-3.0-or-later 源码线。

前置条件

  • Node.js ≥ 20.19
  • 本地 OpenAI 兼容推理后端（Ollama / LM Studio / vLLM / 自建 router） —— 纯本地运行必需
  • macOS / Linux / Windows

步骤

npm install -g owlcoda@latest

首次运行

fresh install 不会默认带维护者模型配置。启动 OwlCoda，然后在 Admin 里配置你 自己的本地 runtime 或云端 provider：

owlcoda
owlcoda admin

如果全局 npm 安装报 EACCES

通常是全局 npm prefix 没写权限。

  • 方案 A — 用户级 prefix： 
    npm config set prefix ~/.local
export PATH=~/.local/bin:$PATH    # 加进你的 shell profile
npm install -g owlcoda@latest
  • 方案 B — 临时跑一次： npx -p owlcoda@latest owlcoda --version
  • 方案 C — sudo： 只有你接受系统级 npm 写入时才用：sudo npm install -g owlcoda@latest

验证安装

which owlcoda
npm ls -g owlcoda --depth=0
owlcoda --version
owlcoda doctor

owlcoda doctor 会检查 Node 版本、本地 runtime 可达性、已配置的模型。如果某项 fail，看 排错。

本地开发构建

全局 owlcoda 默认应该代表 npm 稳定发行版。测试私仓本地构建时，请显式运行 构建产物，不要长期把 WIP 版本 npm link 成全局命令：

npm run build
node dist/cli.js --version
node dist/cli.js

源码与许可证

公开源码在 GitHub：

https://github.com/yeemio/owlcoda

GPL 源码线从 v0.15.0 开始。npm package 仍然是正常安装入口；只携带 编译产物 dist/ 的包，通过 SOURCE.md 指向对应源码。
